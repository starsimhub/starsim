# Library diseases

Example disease models, as `ssl.diseases.X` (and also as `ssl.X`); see the library's README for each.

- `agents.py`: Starsim 3's SIR, SEIR, and SIS, written as code
- `cholera.py`: cholera, with direct and environmental (waterborne) transmission
- `covid.py`: COVID-19, as a SECIR model
- `dengue.py`: dengue, with several serotypes and a mosquito vector
- `ebola.py`: Ebola, with severe disease and transmission from unburied bodies
- `enteric.py`: typhoid, with chronic carriers, and polio, with a paralytic fraction
- `hiv.py`: HIV, with CD4 counts, plus an ART intervention and a CD4 analyzer
- `malaria.py`: malaria, as the Ross-Macdonald model and as the Garki model of immunity
- `measles.py`: measles, as an SEIR model with deaths
- `ncd.py`: an example non-communicable disease, written as code
- `respiratory.py`: influenza, RSV, and pertussis
- `sti.py`: syphilis and gonorrhea
- `tb.py`: tuberculosis, as the LSHTM spectrum-of-disease model
