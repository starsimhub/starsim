# Library diseases

Example disease models, as `ssl.diseases.X` (and most also as `ssl.X`); see the library's README for each.

- `cholera.py`: cholera, with direct and environmental (waterborne) transmission
- `ebola.py`: Ebola, with severe disease and transmission from unburied bodies
- `hiv.py`: HIV, with CD4 counts, plus an ART intervention and a CD4 analyzer
- `measles.py`: measles, as an SEIR model
- `ncd.py`: an example non-communicable disease, written as code
- `agents.py`: Starsim 3's SIR, SEIR, and SIS, written as code
