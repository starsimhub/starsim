# Library networks

Example networks, as `ssl.networks.X` (and most also as `ssl.X`); see the library's README for each.

- `household.py`: household contact networks, built from DHS-style survey data
- `clusters.py`: networks of clusters (e.g. households), and Covasim's population of households, schools, workplaces, and community
- `spatial.py`: networks in which contacts depend on where people are
- `theoretical.py`: theoretical networks (e.g. Erdős–Rényi), for comparison with analytic results and for debugging
