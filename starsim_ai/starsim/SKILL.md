# Starsim

Load the guide for the version of Starsim installed in the user's Python environment, and follow it:

```sh
starsim ai show
```

If the `starsim` command isn't found, run it with the project's Python instead: `python -m starsim ai show`. The guide lists further skills; load one (`starsim ai show <skill>`) only when the task needs it.

This file was installed by `starsim ai`; `starsim ai uninstall` removes it.
