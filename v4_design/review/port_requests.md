# Engine requests from the ports

## STIsim bacterial STIs (stisim-v4, branch v4-port)

1. **Condoms on `ss.SexualNetwork`; network code reading a declared disease's parameter.** `stisim/networks/base.py` `net_beta()` reads `disease.pars.eff_condom`, which for a declared disease is an `ss.par` (Expr), so arithmetic fails. Temporary: `disease.engine.eval(eff_condom)` (`# TODO(v4-rs)`). Want: an edge column `condoms` and a disease-level `eff_condom` handled by `ss.SexualNetwork.net_beta`, or at least a documented accessor for a module parameter's current (modified) value.
2. **An age stratification on the sim replaces the agents' age distribution.** `sim.py` `init_people()`: with an age dimension and no `split=`, `age_data` is built from the split (equal shares, uniform within groups), so `ss.Sim(..., stratify=dict(age=[0, 15, ..., 100]))` gives a median age of 55 instead of 30 and a different epidemic (n_alive 10,572 vs 12,292 after 15 years). Stratifying for results should not change the population. Temporary: `sti.Sim.process_stratify()` makes `ss.People(n_agents)` itself (`# TODO(v4-rs)`). Want: default split from the people's own ages, or a warning.
3. **W209 on a transition meant to be moved only by treatment.** Every STI sim without care warns `ng.cure ... undriven`. Want a way to declare it intended (`ss.Transition(..., undriven=True)`).
4. **Follow-ups registered only through `ss.Sim.__init__`.** `Sim._add_followups()` is not called for a subclass that passes modules via `pars` (sti.Sim now calls it), and a follow-up listed in `interventions` before its parent is skipped by the identity check, so is not marked `triggered` and also runs on its own.
5. **Initial cascade events vs flow results.** Seeds that pass through zero-length dwells at placement (NG `dur_exp=0`, men's 1-week delays at monthly steps) fire `C.enter` events seen by `on=` deliveries at step 0, but are not in the flow results (`seek[0] == 0` while 116 were delivered).
6. **`ss.state('mod.X')` has no events.** For modules built from strings (`sti.Sim(diseases=['ng'])`) a delivery cannot say `on=ss.state('ng.C').enter`; stisim uses `eligible=` a function reading `sim.diseases.ng.graph.states.C.enter.uids` (agents only).
7. **Coverage as a function returning a typed rate** is treated as routine once-per-spell (`Delivery.remembers` only checks `isinstance(coverage, ss.TimePar)`); STITest needs `repeat=True` to get a per-step rate.
8. **Declared ratio results lose their strata with a strain dimension**: `incidence = infection/S` on `ng.stratify(amr=..., kind='strain')` is not stratified (`select()` raises), though `prevalence` is.
9. **Initial prevalence by a network property** (STIsim's `init_prev_data` by risk group and sex work): no `init=` by a property that is not a stratification. Not ported (`NotImplementedError`).

## HPVsim (hpvsim-v4, branch v4-port)

1. **Init time explodes with cross-module modifiers: `Dists.init` recurses through `dist.sim`.** An engine's attribute distribution (`engine.dists.attr_nab_0`) already has `.sim` when `Sim.init_dists()` searches, and `sc.search` follows it back into the sim, finding every distribution again under paths like `declared_1_engine_dists_attr_nab_0_sim_declared_0_...` (repro: two SIS diseases with `nab=ss.attr(ss.uniform(...), on=clear)` and `ss.modify(a.rel_sus, multiply=1 - b.nab)`: 32 dists → 59). For HPV it is 122 → 1,186 dists with one cross-immunity modifier, and each modifier adds ~2.5 s: `hpv.Sim(genotypes=[16, 18])` takes 39 s to init and 3 s to run 50 years. Want: skip `sim` (and engines' `dists`) in the search, or initialize engine dists in `define()`.
2. **Per-act beta in two directions is linearized.** `Agents.infect()` passes `ref = max(beta_p1→p2, beta_p2→p1)` to `net_beta()` and scales the other direction by `c[d]/ref` in `rel_trans`, so the weaker direction is `(1 − (1 − ref)^acts)·(c/ref)` instead of `1 − (1 − c)^acts`. HPV (m2f 0.5, f2m 0.25 per act, ~20 acts a quarter) gets f2m 0.5 per partnership-quarter instead of 0.997. Want: compound each direction's own beta.
3. **`outcome()` of one branch, and flows by destination.** `ss.outcome(cin_exit.to(X), delay=dur_undetected)` raises (`'Event' object has no attribute 'flow_of'`), and `res.cin_exit.select(to='X')` is "not stratified". HPV's cancer onsets and detections (and CIN onsets) are branches of multi-destination exit splits. Temporary: an `ss.func` hook on `cin_exit.to(X)` counts onsets and schedules detection (`# TODO(v4-rs)`, agents only).
4. **A people property in an expression.** `ss.people.female * logf2(P.time)` (proposal 03 §4.1) and `1/ramp(ss.people.age)` in a modifier are `Cond`s, not `Expr`s, and fail at run time (`has no single truth value`). Used instead: `ss.by(sex=[1, 0])` for sex, and a function of the sim for age (agents only).
5. **A dwell whose mean is an attribute expression**: `dur=ss.lognorm_ex(mean=ss.years(2)*(1 - cell), std=...)` raises `float() argument must be ... not 'BinOp'` (implementation.md says a dwell can be an expression of attributes). HPV's severity immunity shortens `dur_precin` at infection; used instead: `ss.modify(precin_exit, multiply=1/(1 - sev))`, which rescales dwells already in progress when `sev` changes.
6. **`init_prev` by age and sex without a stratification.** `init_prev=ss.by(sex=[...])` raises (`'>' not supported between 'by' and 'float'`); by age needs an age stratification (which changes the agents' ages: STIsim #2). HPVsim seeds from age×sex curves; temporary: one share per genotype, the curve's mean over the starting population (`seeding.py`, `# TODO(v4-rs)`). Also no mutually exclusive seeding across diseases (HPVsim's `init_seeding='exclusive'`).
7. **W209 for treatment transitions** (+1 to STIsim #3): every genotype declares `treat_precin/treat_cin/treat_latent` for products; 12 warnings for 4 genotypes. Temporary: filtered in `hpv.Sim.init()` (`# TODO(v4-rs)`).
8. **`Transition | Transition` as an event union** gives a `Cond` with a `None` leaf (`on= takes an event ... not None`); `tr.to(B) | tr2` works, `tr1 | tr2` and `(e1 | e2) | tr3` do not. Used `tr.to(S)` for each.
9. **`ss.probperyear(ss.timeseries(...))`** (already in implementation.md known issues): HPVsim's routine coverage scale-up by year (`prob=[...]` with `years=`) is not ported (`NotImplementedError`).
10. **Products for the sim's diseases.** A product keyed by disease names (`ss.Vaccine(efficacy={'hpv45': ...})`) errors if a named disease is not in the sim, so HPV products are built for the sim's genotypes (`hpv.Sim` calls `set_genotypes()` on products in its deliveries). A product option to ignore absent diseases would let `hpv.vx('nonavalent')` be used in a plain `ss.Sim`.
11. **E212 checks unused array slots.** When people are added the arrays grow with spare capacity (NaN), and `modify.apply()` raises E212 if the amount is NaN anywhere it applies, including slots no agent uses yet: an HPV cross-immunity modifier `1 - (nab16 + 0.5*nab18)` (attributes with `init=0`) fails at the first step with births. Want: check active agents only. Temporary: `hpv.sim._NewAgentImmunity` fills NaN slots with 0 each step (`# TODO(v4-rs)`).
