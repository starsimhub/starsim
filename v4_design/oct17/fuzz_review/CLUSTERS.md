Phase 1 of review 1 (next-reviews.md §1): the harness in `fuzz/` was built and run against the worktree at `03741ba2` (`starsim/` identical to `a20c4f7e`). Each row is one apparent root cause: same transform family, same exception or mismatch signature, same shrunk model shape. Counts come from `fuzz/clusters.py runs/*.jsonl` (first-match rules, reproducible). Every repro in `repros/` is standalone (worktree guard at the top) and prints the two numbers that should agree; `repros/<id>.spec.json` is the shrunk model spec, which `tests/test_fuzz_smoke.py` replays as a strict xfail.

Counts per transform (models run, pass, fail, error, invalid) are in [RUNS.md](RUNS.md). Machine load was 40 to 55 on 20 cores throughout, which limited the sample (see RUNS.md).

Notes:
- C11 was common (36 of 61 `units_sim` models) until the generator moved every model time 0.1 day off the step grid, which the harness now does by default so that other unit problems can surface (`features=dict(offgrid=False)` turns it back on). After that, `units_sim` fails only with C14-size differences.
- `rename_dim` under a stochastic solver is counted in C12, but some of those are D4 (a rename that changes the guessed kind, e.g. `herd` to `region`: `C03b`).
- The transforms that changed nothing on any model (see RUNS.md) are themselves results: the three spellings, `ss.states(3)`, positional transitions, int against float literals, typed values in other units, renamed transitions and modules, exit order (ODE), a one-level stratification, `sim.stratify()`/`stratify=` against `sir.stratify()`, `init()` before `run()`, `save()`/`load()` before a run, the cross-solver comparisons at a fine step, and no generated model the spec calls valid was rejected by v4 (0 `invalid` outside harness bugs).

## Grammar features that could not be made to work

- An inline `ss.par(...)` inside a product (`ss.par(0.6) * 0.5 * I`) raises "Could not find a name for the parameter"; bound to a variable it works. The generator always binds (L36 family).
- `ss.Mobility(...)` needs `kind='space'` unless the dimension is called `patch` or `region` (by design; D4).
- Any analyzer under a compartmental solver (C13); `add_analyzer` therefore runs as agents.
- A delivery with two diseases needs `disease=` (E506, by design).
- `ss.seasonal(peak=...)` is a fraction of the year; a peak of 142 is accepted silently (taken mod 1). Friction, tier 6.
